# Code of Conduct

Loki follows the ECMWF Code of Conduct for software projects:

<https://github.com/ecmwf/codex/blob/main/Principles/Code-Of-Conduct.md>

All contributors, maintainers, and participants are expected to help maintain an
inclusive, respectful, and harassment-free environment in issues, pull requests,
documentation, and other project spaces.

Unacceptable behaviour can be reported to the development team at
[software@ecmwf.int](mailto:software@ecmwf.int). Reports will be reviewed and
handled confidentially and appropriately.
